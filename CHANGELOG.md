# Changelog

## Unreleased

- Review ordinary PDF pages with editable ink, text, pictures and anchored notes in a separate sidecar. Word documents and PowerPoint presentations can be reviewed against a fixed PDF copy.
- Export feedback tied to the exact image or PDF revision, with page positions, full note text and ink samples.
- Use one local workspace on the web for images, existing PDFs and printable notebooks. Reopen a device draft or take a portable, editable copy to another device.
- The English and German product site opens the working tools directly on an illustrated field guide. The on-demand [motion mark](brand/motion/) includes editable source and original sound.

## 1.0.0-rc.2 · 2026-11-02

- Copy, cut, paste and duplicate editable groups across pages, documents and Inklane windows. Text editing retains its own Windows shortcuts.
- Paste pictures and screenshots into either workspace, move or resize them and keep the editable result in the PDF or sidecar. A separate command copies the flattened page or annotated image.
- Name a note from its card, marker or index. Search titles and body text across pages. Note titles also travel with copied objects and standard PDF annotations.
- Rename a notebook independently of its filename, jump to pages, duplicate pages and move them earlier or later with undo.
- Browse a changing image folder using arrow keys or the filename list. Numeric filenames follow Explorer ordering.
- The public English and German site shares the desktop brand, original screenshots and verified Windows release downloads.

## 1.0.0-rc.1 · 2026-11-01

- Home gives image annotation and notebook creation equally visible entry points, with local recent documents and a return-to-document action.
- A single document header, labeled tool rail and contextual footer leave more room for handwriting and image inspection.
- Writing view, fit width, fit page and manual zoom follow the chosen task. Visited pages remember their position during the session.
- Numbered note markers connect a searchable, cross-page index to editable cards. Reading notes leaves a saved document clean.
- Notebook creation offers visible paper choices and a live preview of page geometry, pattern, spacing and margins.
- A new original Margin fold icon ships in eleven Windows sizes. English/German and light/dark workspaces share the same command structure.
- Typing avoids full-document serialization on every edit. Substantial PDF saves run on a separate STA thread with visible progress.
- A per-user Windows x64 installer bundles the runtime and adds Start and Installed apps entries. The update path protects user-created files. Portable distribution remains available.

This candidate introduced the document workspace. Physical device qualification, signing and the PDF maintenance decision remain open.

## 0.1.0-alpha.1 · 2026-11-01

Initial private evaluation build with PNG/JPEG markup, A4/A5 PDF notebooks, editable ink/text/notes, sidecars, recovery and portable distribution. The [original alpha release](https://github.com/dwolken/inklane/releases/tag/v0.1.0-alpha.1) retains its historical build and validation record.
