# Changelog

## 1.0.0-rc.1 · 2026-11-01

- Home gives image annotation and notebook creation equally visible entry points, with local recent documents and a return-to-document action.
- A single document header, labeled tool rail and contextual footer leave more room for handwriting and image inspection.
- Writing view, fit width, fit page and manual zoom follow the chosen task. Visited pages remember their position during the session.
- Numbered note markers connect a searchable, cross-page index to editable cards. Reading notes leaves a saved document clean.
- Notebook creation offers visible paper choices and a live preview of page geometry, pattern, spacing and margins.
- A new original Margin fold icon ships in eleven Windows sizes. English/German and light/dark workspaces share the same command structure.
- Typing avoids full-document serialization on every edit. Substantial PDF saves run on a separate STA thread with visible progress.
- A per-user Windows x64 installer bundles the runtime and adds Start and Installed apps entries. The update path protects user-created files. Portable distribution remains available.

This is the candidate for product acceptance. Physical device qualification, signing and the PDF maintenance decision remain open.

## 0.1.0-alpha.1 · 2026-11-01

Initial private evaluation build with PNG/JPEG markup, A4/A5 PDF notebooks, editable ink/text/notes, sidecars, recovery and portable distribution. The [original alpha release](https://github.com/dwolken/inklane/releases/tag/v0.1.0-alpha.1) retains its historical build and validation record.
